# 白鸽五号策略版本改动记录

## 2026-09-28：V5.5 组合感知盈利减仓

- 移动止盈与动态利润底线共享同一峰值周期，任一成功后本周期不再重复减仓；新峰值至少再提高15%才重新武装。
- 盈利减仓执行前同时检查账户经济多空敞口和同风险类别敞口；正常区间维持60:40，压力区只允许降低净敞口，并保留70:30硬边界。
- 削弱稀缺对冲腿的盈利减仓改为暂缓并记录HOLD，不改变硬止损、30分钟结构失效等风险退出。
- 不修改数据库结构、开仓评分、20倍目标杠杆、调仓时间和单腿3%权益风险预算。

## 2026-09-27：V5.4 组合贡献调仓

- 调仓从“只补目标”升级为受控轮换，但不按单腿盈亏机械止损。
- 仓位分为 Alpha、有效对冲、死资金和数据不足；只在同一经济风险类别内衡量对冲价值。
- 连续两个调仓周期无 Alpha、无对冲贡献后，只有存在同类同方向且至少高1分、空间覆盖两倍成本的候选才释放旧仓。
- 每账户每周期最多轮换一腿，先确认旧仓关闭，替代腿下一扫描再开。
- 初始轮换计数为空，因此上线不会直接处理现有持仓。

## 2026-09-25：失效退出后禁止同周期重开

### 版本判断

- 最近两天已平仓收益约 `-6.70 USDT`，胜率 `53.33%`，利润因子仅 `0.40`。
- 主要拖累来自 `AXTI` 空单和 `SPCX` 多单。其中 `AXTI` 在同一冻结目标周期内多次因硬止损或趋势线失效退出，随后又被执行层补回。
- 根因是目标组合虽然会在调仓周期内冻结，但执行状态此前只持久化“保护单失败”冷却，没有记录普通硬止损或结构失效退出。

### 行为变更

1. 硬止损、30 分钟趋势线失效或明确结构失效导致仓位全平后，按“账户 + 标的 + 方向 + 市场池 + 目标周期”记录重开封锁。
2. 同一目标周期内，执行层会过滤该标的同方向候选，不再把刚止损的腿机械补回。
3. Crypto 的封锁在下一个 12 小时目标周期解除；TradFi 的封锁在下一个日度目标周期解除。
4. 封锁写入 `state/execution_state.json`，服务重启后仍然有效。
5. 移动止盈、盈利保护、普通分批减仓和单级背离减仓不会触发封锁；只有确认全平的失效型退出才触发。
6. 状态接口新增 `reentries_blocked`、`exited_target_reentries_blocked`，用于审计被拦截的重复开仓。

### 保持不变

- 不修改当前持仓，不主动平仓，不改变目标组合和调仓时间。
- 不修改 20 倍杠杆、1.5% 软件硬止损、交易所原生止损、仓位上限或多空权重。
- 移动止盈和已有退出层级保持原样。
